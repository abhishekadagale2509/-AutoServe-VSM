# -AutoServe-VSM
AutoServe-VSM is a web-based Vehicle Service Management System that allows customers to register vehicles, book service appointments, track service status, view job cards and make online payments. Mechanics can manage service appointments and update job cards, while administrators manage customers, mechanics and appointments. The system is developed using React, Spring Boot, MySQL and Spring Security with JWT authentication, and includes a Vehicle Tips Microservice that provides maintenance tips based on the vehicle type.
