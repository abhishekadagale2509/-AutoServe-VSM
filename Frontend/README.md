# Frontend

React frontend for AutoServe-VSM.

## Technologies

- React.js
- React Router
- Axios
- Bootstrap
- CSS

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Folder Structure

```text
src/
│
├── api
├── assets
├── components
├── pages
├── router
├── services
└── main.jsx
```
